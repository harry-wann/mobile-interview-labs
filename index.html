技術面試強化學習手冊

這份手冊把交易所 Mobile 工程師面試的重點方向,整理成可互動的學習教材:每章都有語法/概念講解、使用情境、隨堂練習(點擊展開解答),以及章末的自我檢核清單(可勾選,進度會記在瀏覽器裡)。

五個章節

  1. Java 基礎到進階 — 型別系統、物件導向、集合框架、泛型、例外、Lambda/Stream、並發、JVM。每個主題都附「什麼情境用它」與高頻面試題。
  2. Objective-C 完整教學 — 從心智模型到進階語法,每節對照 Swift;最後用一個小 App「CoinTracker」把所有語法實際用一遍,並附概念對照表。
  3. 交易所 App 架構設計 — 從需求特性推導分層架構,行情資料流、下單正確性、安全設計、模組化,附架構圖與一分鐘總結版。
  4. 資料結構基礎到進階 — 複雜度、九大結構的「長相/速度/時機」、排序,與交易所情境的綜合面試題組。
  5. 多執行緒安全:四語言對照 — 原子性/可見性/死結的原理,Swift、Objective-C、Java、Kotlin 各自的工具箱,並用同一個「行情快取」場景以四種語言實作對照,附實務事故案例分析。

建議讀法

  • 第一輪(理解):照章節順序讀,每個隨堂練習先自己想過再點開解答。
  • 第二輪(動手):Java 章的綜合實作、Objective-C 的 CoinTracker 實際在 IDE/Xcode 做出來。
  • 面試前一天:只看各章的「自我檢核清單」與速查表,沒把握的條目回去重讀該節。

小提醒:面試回答的通用結構是「結論 → 原因 → 取捨 → 實例」。例如被問 HashMap:先說是什麼、再講原理、然後說什麼情況不該用它、最後舉一個你用過的場景。
