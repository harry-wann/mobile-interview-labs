Objective-C 完整教學:從零到寫出一個小 App

本章目標:從零開始學 Objective-C——從變數宣告、印出、流程控制一步步來,不假設你會 Swift(會一點 Java 或 JavaScript 就夠)。前半是語法教學,後半用一個小 App「CoinTracker 幣價追蹤器」把所有語法實際用一遍。 各節附的「Swift 對照」是給之後學 Swift 時回頭看的,第一次讀跳過也完全不影響。 為什麼要學:成立較久的交易所,App 裡幾乎一定有 Objective-C 舊程式碼,看懂並能維護它是行動工程師的實際需求。

1. 心智模型:Objective-C 是什麼

(這一節先建立大方向,範例裡的語法第 2 節會從頭一個一個教——第一次看不懂很正常,讀完第 2 節回頭看就通了。)

  • Objective-C = C 語言 + 物件系統。變數、if、for 這些基本語法和 Java 幾乎一樣(都源自 C)。
  • 物件方法的呼叫寫成中括號:[obj doSomething],意思是「對 obj 送出 doSomething 這個訊息」——程式執行到那一刻才去找這個方法的實作(術語叫動態派發 dynamic dispatch)。
  • 一個類別拆成兩個檔案:.h(標頭檔 header,對外公開「我有哪些方法」)+ .m(實作檔 implementation,方法的內容)。Java 一個 class 一個檔案就好,這個分離是新手最先撞到的差異。
// Greeter.h —— 對外公開的介面
#import <Foundation/Foundation.h>

@interface Greeter : NSObject
- (NSString *)greet:(NSString *)name;
@end

// Greeter.m —— 實作
#import "Greeter.h"

@implementation Greeter
- (NSString *)greet:(NSString *)name {
    return [NSString stringWithFormat:@"你好, %@!", name];
}
@end

// 使用
Greeter *g = [[Greeter alloc] init];    // 配置記憶體 + 初始化
NSString *message = [g greet:@"Harry"]; // 送訊息
NSLog(@"%@", message);

對照 Swift:

Swift Objective-C
let g = Greeter() Greeter *g = [[Greeter alloc] init];
g.greet(name: "Harry") [g greet:@"Harry"]
"你好 \(name)" [NSString stringWithFormat:@"你好 %@", name]
print(x) NSLog(@"%@", x);

注意:物件變數一定是指標(NSString *),@ 開頭的都是 Objective-C 的擴充(@"字串"、@interface、@[]…)。

2. 從零開始:變數、印出、流程控制、方法呼叫

2.1 變數宣告與常數

格式和 Java 一樣:型別 名字 = 初始值;(每行結尾要分號)

// --- 基本型別:值直接存在變數裡 ---
int age = 25;                // 整數
double ratio = 0.75;         // 小數
BOOL isOpen = YES;           // 布林值,寫 YES / NO(不是 true/false)

// 實務上更常用這兩個(功能一樣,只是依平台自動選最佳大小):
NSInteger count = 42;        // 取代 int
CGFloat x = 10.5;            // 取代 double,UI 座標慣用

// --- 常數:前面加 const,之後不能再改 ---
const NSInteger maxRetry = 3;
// maxRetry = 5;   // ← 編譯錯誤

// --- 字串:字串是「物件」,寫法有兩個新記號 ---
NSString *name = @"Harry";

字串那行拆開看,兩個新記號:

  • @"...":Objective-C 的字串字面值。凡是 @ 開頭的都是 Objective-C 對 C 的擴充(之後會看到 @[] 陣列、@interface 類別……)。
  • *(指標):基本型別的變數直接裝「值」;物件的變數裝的是「物件在記憶體裡的位址」,這種變數叫指標(pointer),宣告時名字前面加 *。

先背兩條規則就能動手寫,原理後面章節慢慢懂: 1. 物件型別(大寫 NS 開頭的幾乎都是)→ 變數加 * 2. 字串、陣列等字面值 → 前面加 @

2.2 印出:NSLog

NSLog(@"Hello!");                              // 印固定文字
NSLog(@"你好, %@!", name);                     // %@ = 這裡放一個「物件」(字串、陣列…)
NSLog(@"年齡 %ld、比率 %.2f", (long)age, ratio); // %ld = 整數、%.2f = 小數取兩位

和 Java 的 System.out.printf 同一套邏輯:字串裡放格式符(format specifier)當佔位,後面依序補值。最常用三個:%@ 物件、%ld 整數(NSInteger 慣例轉 (long))、%f 小數。

✏️ 隨堂練習:宣告幣種名稱(字串)、價格(CGFloat)、是否為最愛(BOOL),用一行 NSLog 印出「BTC 價格 16500000.00,最愛:1」。(點擊看解答)
NSString *symbol = @"BTC";
CGFloat price = 16500000;
BOOL favorite = YES;
NSLog(@"%@ 價格 %.2f,最愛:%d", symbol, price, favorite);  // BOOL 用 %d 印,YES=1 NO=0

檢查點:symbol 是物件所以有 *、字面值有 @;price、favorite 是基本型別,都沒有。

2.3 流程控制:和 Java 幾乎一樣

// if / else
if (price > 1000000) {
    NSLog(@"高價幣");
} else if (price > 1000) {
    NSLog(@"中價幣");
} else {
    NSLog(@"低價幣");
}

// for 迴圈
for (int i = 0; i < 5; i++) {
    NSLog(@"第 %d 次", i);
}

// while
while (isOpen) { /* ... */ break; }

// switch(只能用整數/enum,不能 switch 字串——這點比 Java 舊)
switch (age) {
    case 18: NSLog(@"剛成年"); break;
    default: break;
}

這一段沒有新東西——C 家族的流程控制你已經會了(Java、JavaScript 都一樣)。

2.4 方法呼叫:中括號怎麼讀

這是 Objective-C 長相最不一樣的地方,學會讀就不可怕:

NSString *upper = [name uppercaseString];
// 讀法:「對 name 這個物件,呼叫 uppercaseString 方法,結果存進 upper」
// Java 的同一句:String upper = name.toUpperCase();

NSString *msg = [NSString stringWithFormat:@"你好 %@", name];
// 「對 NSString 這個類別,呼叫 stringWithFormat: 方法」(類別方法,類似 Java 的 static 方法)

帶參數的方法,參數寫在冒號後面;多個參數時,方法名被拆成好幾段:

[service fetchPrice:@"BTC" currency:@"JPY"];
//       └─────┬────┘      └───┬────┘
//        第一段:參數1      第二段:參數2
// 這個方法的全名是「fetchPrice:currency:」——每一段都是名字的一部分
// Java 的同一句:service.fetchPrice("BTC", "JPY");

好處:讀起來像句子,每個參數前面都有說明它是什麼。呼叫可以巢狀:

Greeter *g = [[Greeter alloc] init];
// 由內往外讀:先 [Greeter alloc](跟類別要一塊記憶體),再對結果呼叫 init(初始化)
// Java 的同一句:Greeter g = new Greeter();  ← new 做掉的兩件事,Objective-C 拆成 alloc + init

2.5 基本型別與字串的常用操作

// 可變字串:NSMutableString(Mutable = 可變的;不可變/可變是兩個不同類別)
NSMutableString *log = [NSMutableString string];
[log appendString:@"開始..."];

// NSNumber:把基本型別「包成物件」(之後會看到:集合只能放物件,不能放 int!)
NSNumber *n1 = @42;                  // @ 字面值語法:int → NSNumber
NSNumber *n2 = @(count * 2);         // 表達式要加括號
NSInteger back = [n1 integerValue];  // 拆回基本型別

// 字串常用操作
NSString *symbol = @"BTC/JPY";
NSUInteger len = symbol.length;                       // 長度
BOOL has = [symbol containsString:@"BTC"];            // 包含?
NSArray<NSString *> *parts =
    [symbol componentsSeparatedByString:@"/"];        // 切割 → ["BTC", "JPY"]

使用情境:NSArray/NSDictionary 不能放 int,所以常看到 @42、@YES 這種包裝;從集合拿出來要手動拆箱(Java 會自動裝箱拆箱,Objective-C 要自己來)。

✏️ 隨堂練習:宣告一個可變字串,迴圈 append 三個幣種名稱,用「、」分隔。(點擊看解答)
NSArray<NSString *> *coins = @[@"BTC", @"ETH", @"XRP"];
NSMutableString *result = [NSMutableString string];
for (NSUInteger i = 0; i < coins.count; i++) {
    if (i > 0) [result appendString:@"、"];
    [result appendString:coins[i]];
}
NSLog(@"%@", result);   // BTC、ETH、XRP

// 其實一行也行:
NSString *joined = [coins componentsJoinedByString:@"、"];

3. 集合:NSArray / NSDictionary / NSSet

// 不可變 vs 可變是「不同類別」(Swift 是用 let/var 區分)
NSArray<NSString *> *symbols = @[@"BTC", @"ETH"];          // 字面值
NSMutableArray<NSString *> *watchlist = [symbols mutableCopy];
[watchlist addObject:@"SOL"];
[watchlist removeObjectAtIndex:0];

NSDictionary<NSString *, NSNumber *> *prices = @{
    @"BTC": @16500000,
    @"ETH": @580000,
};
NSNumber *btc = prices[@"BTC"];          // 下標語法
NSMutableDictionary *mdict = [prices mutableCopy];
mdict[@"SOL"] = @32000;

// 遍歷
for (NSString *key in prices) {
    NSLog(@"%@ = %@", key, prices[key]);
}
[prices enumerateKeysAndObjectsUsingBlock:^(NSString *key, NSNumber *val, BOOL *stop) {
    if ([key isEqualToString:@"ETH"]) *stop = YES;   // 可中途停止
}];

重點:

  • <NSString *> 是「輕量泛型」,只有編譯期提示,執行期不檢查(放錯型別不會立刻爆)。
  • 查無 key 回傳 nil,不會當掉——對 nil 送訊息是合法的,什麼都不做並回傳 0/nil。這是 Objective-C 和 Java/Swift 最大的行為差異,好處是少掉很多判空,壞處是錯誤被默默吞掉。

4. 類別完整寫法:屬性、初始化、方法

// Coin.h
#import <Foundation/Foundation.h>

NS_ASSUME_NONNULL_BEGIN   // 這個範圍內的指標預設 nonnull(給 Swift 混編看的)

@interface Coin : NSObject

@property (nonatomic, copy)   NSString *symbol;     // 字串用 copy
@property (nonatomic, strong) NSNumber *price;      // 物件用 strong
@property (nonatomic, assign) NSInteger rank;       // 基本型別用 assign
@property (nonatomic, assign, getter=isFavorite) BOOL favorite;

// 指定初始化器
- (instancetype)initWithSymbol:(NSString *)symbol price:(NSNumber *)price;

// 類別方法(等同 Swift 的 static/class func),+ 開頭
+ (instancetype)coinWithSymbol:(NSString *)symbol;

- (NSString *)displayText;

@end

NS_ASSUME_NONNULL_END

// Coin.m
#import "Coin.h"

@implementation Coin

- (instancetype)initWithSymbol:(NSString *)symbol price:(NSNumber *)price {
    self = [super init];            // 固定寫法:先呼叫父類,再檢查
    if (self) {
        _symbol = [symbol copy];    // init 裡直接碰底層變數 _symbol,不走 setter
        _price = price;
    }
    return self;
}

+ (instancetype)coinWithSymbol:(NSString *)symbol {
    return [[self alloc] initWithSymbol:symbol price:@0];
}

- (NSString *)displayText {
    return [NSString stringWithFormat:@"%@ ¥%@", self.symbol, self.price];
}

@end

@property 的修飾詞(面試必考):

修飾詞 意義 用在
strong 強參考,持有物件(預設) 一般物件
weak 弱參考,不持有;物件釋放後自動變 nil delegate、避免循環參考
copy 設值時複製一份 NSString、block(防止外部可變物件偷改)
assign 直接賦值,不管記憶體 基本型別(int、BOOL…)
nonatomic 不加鎖,快(幾乎都用這個) 幾乎所有屬性
atomic getter/setter 加鎖(預設但少用) 極少

@property 會自動產生:底層實例變數 _symbol + getter symbol + setter setSymbol:。self.symbol = x 走 setter;_symbol = x 直接改變數。

✏️ 隨堂練習:為什麼 NSString 屬性建議用 copy 而不是 strong?(點擊看解答)

因為 NSMutableString 是 NSString 的子類別,外部可以傳一個可變字串進來。若用 strong,外部之後修改那個可變字串,你的屬性內容會跟著變(資料被偷改);用 copy 會在設值當下複製一份不可變版本,之後外部怎麼改都影響不到你。

5. 記憶體管理:ARC 與循環參考

Objective-C 用參考計數:每個物件有 retainCount,歸零就釋放。ARC(Automatic Reference Counting)讓編譯器自動插入 retain/release,你不用手寫,但循環參考仍要自己打破(和 Swift 完全相同的概念)。

// 經典循環:A 強參考 B,B 強參考 A → 誰都死不了(記憶體洩漏)
@interface Downloader : NSObject
@property (nonatomic, copy) void (^completion)(NSData *data);
@end

// ❌ self 持有 downloader,block 又捕獲了 self → 循環
self.downloader.completion = ^(NSData *data) {
    [self handleData:data];        // block 強捕獲 self
};

// ✅ weak-strong dance
__weak typeof(self) weakSelf = self;
self.downloader.completion = ^(NSData *data) {
    __strong typeof(weakSelf) strongSelf = weakSelf;  // 進 block 先變回強參考
    if (!strongSelf) return;                           // self 可能已被釋放
    [strongSelf handleData:data];
};

面試常問:

  • delegate 為什麼宣告成 weak?→ 通常「子物件的 delegate 指回父物件」,若用 strong 就形成循環參考。
  • MRC(Manual Reference Counting,手動管理記憶體的舊時代)的 retain/release/autorelease?→ 知道概念即可:ARC 出現之前,工程師要自己手寫「retain(計數 +1)/ release(計數 −1)」而且必須成對,漏寫就洩漏或崩潰;@autoreleasepool 是那個時代留下來、現在仍有用的工具——迴圈內大量產生暫時物件時,用它讓物件即時釋放,不會堆到迴圈結束。

6. 協定(Protocol)與 Delegate 模式

// 定義協定(等同 Swift protocol)
@protocol PriceServiceDelegate <NSObject>
- (void)priceService:(id)service didUpdatePrice:(NSNumber *)price forSymbol:(NSString *)symbol;
@optional                                      // Objective-C 特有:可選方法
- (void)priceServiceDidDisconnect:(id)service;
@end

@interface PriceService : NSObject
@property (nonatomic, weak) id<PriceServiceDelegate> delegate;   // 注意 weak!
- (void)startStreaming;
@end

// PriceService.m 內部通知 delegate
- (void)onNewTick:(NSNumber *)price symbol:(NSString *)symbol {
    [self.delegate priceService:self didUpdatePrice:price forSymbol:symbol];

    // @optional 的方法呼叫前必須檢查有沒有實作:
    if ([self.delegate respondsToSelector:@selector(priceServiceDidDisconnect:)]) {
        [self.delegate priceServiceDidDisconnect:self];
    }
}

使用情境:整個 UIKit 都是這個模式(UITableViewDelegate、UITextFieldDelegate)。「服務不認識畫面,只透過協定回呼」——和 Java 的介面注入是同一個解耦思想。

7. Block(Objective-C 的閉包)

// 宣告語法(最難記的部分):回傳型別 (^名字)(參數)
void (^simpleBlock)(void) = ^{ NSLog(@"hi"); };
NSInteger (^add)(NSInteger, NSInteger) = ^NSInteger(NSInteger a, NSInteger b) {
    return a + b;
};
add(2, 3);   // 5

// 當方法參數(最常見用法:完成回呼)
- (void)fetchPriceForSymbol:(NSString *)symbol
                 completion:(void (^)(NSNumber * _Nullable price, NSError * _Nullable error))completion;

// 呼叫
[service fetchPriceForSymbol:@"BTC" completion:^(NSNumber *price, NSError *error) {
    if (error) { NSLog(@"失敗: %@", error); return; }
    NSLog(@"價格: %@", price);
}];

// 捕獲外部變數:預設捕獲「值」,要修改需加 __block
__block NSInteger total = 0;
void (^accumulate)(NSInteger) = ^(NSInteger x) { total += x; };
accumulate(10);   // total == 10

記法:宣告 回傳 (^名)(參數)、實作 ^回傳(參數){...}。背不起來很正常,工程師都在查 [goshdarnblocksyntax 這類速查表]——面試能手寫出「completion handler 模式」就夠了。

block 屬性要用 copy:block 建立在堆疊上,copy 把它搬到堆積,否則離開作用域就失效(ARC 下多數情境會自動 copy,但宣告 copy 是明確的慣例)。

8. 分類(Category)與擴展(Extension)

// Category:幫「別人的類別」加方法(不能加實例變數)
// NSString+Trading.h
@interface NSString (Trading)
- (BOOL)isValidSymbol;        // "BTC/JPY" 這種格式才合法
@end

// NSString+Trading.m
@implementation NSString (Trading)
- (BOOL)isValidSymbol {
    return [self componentsSeparatedByString:@"/"].count == 2;
}
@end

// 之後所有 NSString 都有這個方法:
[@"BTC/JPY" isValidSymbol];   // YES

// Class Extension(匿名分類):寫在 .m 開頭,存放「私有屬性/方法」
// PriceService.m
@interface PriceService ()                 // 括號空白 = extension
@property (nonatomic, strong) NSTimer *timer;   // 外部看不到
@end

對照 Swift:Category ≒ extension;Class Extension 的用途(藏私有成員)在 Swift 由 private 直接解決。

9. KVC / KVO 與 NSNotificationCenter

先把兩個縮寫說清楚:

  • KVC = Key-Value Coding(鍵值存取):不呼叫 getter/setter,改用「屬性名字的字串」存取屬性——[coin setValue:x forKey:@"price"] 等於 coin.price = x,但名字是執行期才給的字串。
  • KVO = Key-Value Observing(鍵值觀察):訂閱「某個物件的某個屬性」,屬性一變就收到通知。
// KVC:用字串名字存取屬性(動態特性的展現)
[coin setValue:@16500000 forKey:@"price"];
NSNumber *p = [coin valueForKey:@"price"];

// KVO:觀察屬性變化
[coin addObserver:self forKeyPath:@"price" options:NSKeyValueObservingOptionNew context:nil];

- (void)observeValueForKeyPath:(NSString *)keyPath ofObject:(id)object
                        change:(NSDictionary *)change context:(void *)context {
    if ([keyPath isEqualToString:@"price"]) {
        NSLog(@"價格變了: %@", change[NSKeyValueChangeNewKey]);
    }
}
// ⚠️ dealloc 前必須 removeObserver,否則崩潰(經典事故題)

// NSNotificationCenter:一對多廣播
[[NSNotificationCenter defaultCenter] postNotificationName:@"PriceDidUpdate"
                                                    object:nil
                                                  userInfo:@{@"symbol": @"BTC", @"price": @16500000}];
[[NSNotificationCenter defaultCenter] addObserver:self
                                         selector:@selector(onPriceUpdate:)
                                             name:@"PriceDidUpdate" object:nil];

三種溝通方式選擇(面試常問):

方式 關係 情境
Delegate 一對一、需要回傳值/互動 TableView 要資料
Block callback 一對一、一次性非同步結果 網路請求完成
Notification 一對多、鬆散廣播 登入狀態改變,全 App 都要知道
KVO 觀察「屬性」本身 進度條綁 progress 屬性

10. GCD:多執行緒

GCD = Grand Central Dispatch,Apple 的工作佇列框架。心智模型:你不直接操作執行緒,而是把工作(block)丟進佇列(queue),系統負責分配執行緒去執行。佇列分兩種:串列(serial,一次做一件、照順序)與並發(concurrent,多件同時做);另外有一條特殊的主佇列(main queue)= 主執行緒,所有 UI 更新都必須回到這裡。

// 背景做事,完成後回主執行緒更新 UI(最重要的模板,背起來)
dispatch_async(dispatch_get_global_queue(QOS_CLASS_USER_INITIATED, 0), ^{
    NSData *data = [self downloadPrices];        // 背景執行緒
    dispatch_async(dispatch_get_main_queue(), ^{
        [self refreshUIWithData:data];           // 主執行緒(UI 只能在這裡動!)
    });
});

// 串列佇列:保護共享資料(同一時間只有一件事在跑)
dispatch_queue_t serialQueue = dispatch_queue_create("com.app.orders", DISPATCH_QUEUE_SERIAL);
dispatch_async(serialQueue, ^{ /* 安全地修改訂單陣列 */ });

// dispatch_group:等多個非同步工作全部完成
dispatch_group_t group = dispatch_group_create();
dispatch_group_enter(group);
[self fetchBTC:^{ dispatch_group_leave(group); }];
dispatch_group_enter(group);
[self fetchETH:^{ dispatch_group_leave(group); }];
dispatch_group_notify(group, dispatch_get_main_queue(), ^{
    NSLog(@"全部完成,更新畫面");
});

12.3 Service:模擬行情推送(用到:協定+delegate、block、GCD、extension、NSTimer)

// PriceFeedService.h
#import <Foundation/Foundation.h>
#import "Coin.h"
NS_ASSUME_NONNULL_BEGIN

@class PriceFeedService;   // 前向宣告

@protocol PriceFeedServiceDelegate <NSObject>
- (void)priceFeed:(PriceFeedService *)service didUpdateCoin:(Coin *)coin;
@optional
- (void)priceFeedDidStart:(PriceFeedService *)service;
@end

typedef void (^CoinsLoadedBlock)(NSArray<Coin *> *coins);   // block 型別取別名

@interface PriceFeedService : NSObject
@property (nonatomic, weak) id<PriceFeedServiceDelegate> delegate;   // weak 防循環!
- (void)loadInitialCoinsWithCompletion:(CoinsLoadedBlock)completion;
- (void)startStreaming;
- (void)stopStreaming;
@end

NS_ASSUME_NONNULL_END

// PriceFeedService.m
#import "PriceFeedService.h"

@interface PriceFeedService ()                 // Class Extension:私有成員
@property (nonatomic, strong) NSTimer *timer;
@property (nonatomic, strong) NSMutableArray<Coin *> *coins;
@end

@implementation PriceFeedService

- (void)loadInitialCoinsWithCompletion:(CoinsLoadedBlock)completion {
    // GCD:模擬網路請求 —— 背景組資料、回主執行緒回呼
    dispatch_async(dispatch_get_global_queue(QOS_CLASS_USER_INITIATED, 0), ^{
        NSMutableArray<Coin *> *list = [NSMutableArray array];
        NSDictionary<NSString *, NSNumber *> *seed = @{
            @"BTC/JPY": @16500000, @"ETH/JPY": @580000, @"XRP/JPY": @350,
        };
        for (NSString *symbol in seed) {
            [list addObject:[[Coin alloc] initWithSymbol:symbol price:seed[symbol]]];
        }
        [NSThread sleepForTimeInterval:0.5];   // 假裝有網路延遲
        self.coins = list;
        dispatch_async(dispatch_get_main_queue(), ^{
            completion([list copy]);           // 回傳不可變副本(防禦性複製)
        });
    });
}

- (void)startStreaming {
    __weak typeof(self) weakSelf = self;       // weak-strong dance 防循環
    self.timer = [NSTimer scheduledTimerWithTimeInterval:1.0 repeats:YES block:^(NSTimer *t) {
        __strong typeof(weakSelf) strongSelf = weakSelf;
        if (!strongSelf) return;
        [strongSelf tick];
    }];
    if ([self.delegate respondsToSelector:@selector(priceFeedDidStart:)]) {   // @optional 檢查
        [self.delegate priceFeedDidStart:self];
    }
}

- (void)tick {
    if (self.coins.count == 0) return;
    Coin *coin = self.coins[arc4random_uniform((uint32_t)self.coins.count)];
    double delta = ((double)arc4random_uniform(200) - 100.0) / 1000.0;   // ±10%
    double newPrice = coin.price.doubleValue * (1.0 + delta);
    coin.trend = delta > 0 ? PriceTrendUp : (delta < 0 ? PriceTrendDown : PriceTrendFlat);
    coin.price = @(newPrice);                  // 觸發 KVO!
    [self.delegate priceFeed:self didUpdateCoin:coin];   // 通知 delegate
}

- (void)stopStreaming { [self.timer invalidate]; self.timer = nil; }

@end

12.4 ViewController(用到:delegate 實作、KVO、Notification、集合操作)

// ViewController.m
#import "ViewController.h"
#import "PriceFeedService.h"
#import "NSString+CoinTracker.h"

static NSString * const kFavoriteChangedNote = @"FavoriteChanged";

@interface ViewController () <UITableViewDataSource, UITableViewDelegate, PriceFeedServiceDelegate>
@property (nonatomic, strong) UITableView *tableView;
@property (nonatomic, strong) PriceFeedService *service;
@property (nonatomic, strong) NSArray<Coin *> *coins;
@end

@implementation ViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    self.title = @"CoinTracker";

    self.tableView = [[UITableView alloc] initWithFrame:self.view.bounds];
    self.tableView.dataSource = self;     // UIKit 自己就是 delegate 模式
    self.tableView.delegate = self;
    [self.view addSubview:self.tableView];

    self.service = [[PriceFeedService alloc] init];
    self.service.delegate = self;

    // block 回呼拿初始資料
    __weak typeof(self) weakSelf = self;
    [self.service loadInitialCoinsWithCompletion:^(NSArray<Coin *> *coins) {
        weakSelf.coins = coins;
        [weakSelf.tableView reloadData];
        [weakSelf.service startStreaming];
        // 示範 KVO:觀察第一個幣的價格
        [coins.firstObject addObserver:weakSelf forKeyPath:@"price"
                               options:NSKeyValueObservingOptionNew context:nil];
    }];

    // Notification:聽「加入最愛」廣播
    [[NSNotificationCenter defaultCenter] addObserver:self selector:@selector(onFavoriteChanged:)
                                                 name:kFavoriteChangedNote object:nil];
}

// --- PriceFeedServiceDelegate ---
- (void)priceFeed:(PriceFeedService *)service didUpdateCoin:(Coin *)coin {
    NSUInteger idx = [self.coins indexOfObject:coin];
    if (idx == NSNotFound) return;
    NSIndexPath *path = [NSIndexPath indexPathForRow:idx inSection:0];
    [self.tableView reloadRowsAtIndexPaths:@[path] withRowAnimation:UITableViewRowAnimationNone];
}

// --- KVO 回呼 ---
- (void)observeValueForKeyPath:(NSString *)keyPath ofObject:(id)object
                        change:(NSDictionary *)change context:(void *)context {
    if ([keyPath isEqualToString:@"price"]) {
        NSLog(@"[KVO] 價格更新: %@", change[NSKeyValueChangeNewKey]);
    }
}

// --- Notification 回呼 ---
- (void)onFavoriteChanged:(NSNotification *)note {
    NSLog(@"[Notification] 最愛清單變更: %@", note.userInfo);
}

// --- UITableViewDataSource ---
- (NSInteger)tableView:(UITableView *)tv numberOfRowsInSection:(NSInteger)section {
    return self.coins.count;
}

- (UITableViewCell *)tableView:(UITableView *)tv cellForRowAtIndexPath:(NSIndexPath *)indexPath {
    UITableViewCell *cell = [tv dequeueReusableCellWithIdentifier:@"cell"];
    if (!cell) {
        cell = [[UITableViewCell alloc] initWithStyle:UITableViewCellStyleValue1 reuseIdentifier:@"cell"];
    }
    Coin *coin = self.coins[indexPath.row];
    NSString *name = coin.isFavorite ? [@"★ " stringByAppendingString:coin.symbol] : coin.symbol;
    cell.textLabel.text = [name trendArrowForTrend:coin.trend];     // 用到 Category
    cell.detailTextLabel.text = [coin displayPrice];
    cell.detailTextLabel.textColor =
        coin.trend == PriceTrendUp   ? UIColor.systemGreenColor :
        coin.trend == PriceTrendDown ? UIColor.systemRedColor   : UIColor.labelColor;
    return cell;
}

// --- 點一列 = 切換最愛 ---
- (void)tableView:(UITableView *)tv didSelectRowAtIndexPath:(NSIndexPath *)indexPath {
    Coin *coin = self.coins[indexPath.row];
    coin.favorite = !coin.isFavorite;
    [[NSNotificationCenter defaultCenter] postNotificationName:kFavoriteChangedNote
        object:nil userInfo:@{@"symbol": coin.symbol, @"favorite": @(coin.isFavorite)}];
    [tv reloadRowsAtIndexPaths:@[indexPath] withRowAnimation:UITableViewRowAnimationAutomatic];
}

// --- 清理(KVO / Notification 都要解除!)---
- (void)dealloc {
    [self.coins.firstObject removeObserver:self forKeyPath:@"price"];
    [[NSNotificationCenter defaultCenter] removeObserver:self];
    [self.service stopStreaming];
}

@end
